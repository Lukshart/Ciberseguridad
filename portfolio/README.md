# Portafolio de Gestión de Seguridad

Esta sección presenta evidencia de un ciclo práctico de gestión de seguridad: identificar, priorizar, proteger, verificar y medir. Es complementaria a los laboratorios académicos del repositorio; los laboratorios originales se preservan sin cambios.

## Principios de publicación

- No incluir contraseñas, tokens, claves privadas, direcciones IP públicas ni datos personales.
- Usar evidencias anonimizadas, fechas y alcance claros.
- Distinguir entre laboratorio, demostración y entorno productivo.
- Registrar el riesgo residual y la verificación posterior a toda remediación.

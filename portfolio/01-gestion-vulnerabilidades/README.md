# Gestión de vulnerabilidades

## Objetivo

Mantener un registro trazable de hallazgos, desde su identificación hasta su cierre validado. La severidad técnica se combina con el contexto del activo para priorizar de forma proporcional al riesgo.

## Flujo de trabajo

1. Identificar el activo y el hallazgo con evidencia segura.
2. Validar alcance, exposición e impacto potencial.
3. Asignar prioridad y fecha objetivo.
4. Aplicar o planificar la remediación.
5. Verificar el resultado y documentar el riesgo residual.

## Criterio de prioridad

| Prioridad | Ejemplo de condición | Objetivo sugerido |
|---|---|---|
| Crítica | Exposición explotable de un activo crítico | 24–72 horas |
| Alta | Compromiso significativo o acceso no autorizado probable | 7 días |
| Media | Debilidad con controles compensatorios | 30 días |
| Baja | Mejora preventiva o de baja exposición | 90 días |

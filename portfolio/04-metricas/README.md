# Métricas de seguridad

Las métricas deben orientar decisiones, no solo producir números. Se registran por período, alcance y fuente de evidencia.

| Indicador | Fórmula | Meta inicial |
|---|---|---:|
| Cumplimiento de SLA crítico | críticos cerrados dentro de plazo / críticos cerrados × 100 | ≥ 90 % |
| MTTR por prioridad | suma de días hasta cierre / hallazgos cerrados | Tendencia descendente |
| Cobertura MFA | activos administrativos con MFA / activos administrativos × 100 | 100 % |
| Cobertura HTTPS | servicios con HTTPS forzado / servicios web × 100 | 100 % |
| Conformidad de hardening | controles conformes / controles evaluados × 100 | ≥ 95 % |
| Riesgo alto abierto | riesgos altos sin tratamiento | 0 |

Consulta un [tablero de ejemplo](tablero-ejemplo.md) para registrar resultados sin exponer información sensible.
